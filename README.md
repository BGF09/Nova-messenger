# NULL Messenger

NULL Messenger — мессенджер экосистемы NULL для Windows и Android на общей Compose Multiplatform-основе.

## Статус основы

- [x] Выделена отдельная ветка для кроссплатформенной разработки.
- [x] Добавлены модули Android и Windows desktop.
- [x] Создан общий тёмный интерфейс NULL с mint-акцентом.
- [x] Добавлены отдельные GitHub Actions-сборки APK и Windows MSI.
- [ ] Подключить существующую авторизацию NULL через Supabase.
- [ ] Добавить профили, поиск пользователей и реальные диалоги.
- [ ] Реализовать доставку сообщений и синхронизацию в реальном времени.
- [ ] Добавить аватары, вложения, уведомления и настройки приватности.

## Сборка

Требуется JDK 17 и Gradle 8.14.3.

- Android APK: `gradle :androidApp:assembleDebug`
- Windows MSI (на Windows): `gradle :desktopApp:packageMsi`

## Важно

Сейчас это стартовый UI-прототип: сообщения отображаются локально и пока не отправляются в сеть. Не вводите в приложение реальные пароли — серверная авторизация и безопасные политики доступа будут добавлены отдельным этапом.
