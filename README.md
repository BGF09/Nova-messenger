# NULL Messenger

NULL Messenger — кроссплатформенный проект мессенджера экосистемы NULL для Android и Windows на Compose Multiplatform.

## Что уже есть в интерфейсе

- [x] Экран ввода номера телефона.
- [x] Демо-режим с главным экраном и списком примеров чатов.
- [x] Экран диалога с локальной отправкой демонстрационных сообщений.
- [x] Экран профиля: имя, username и описание (локально в демо-сеансе).
- [x] Экран виртуальных подарков и демо-коллекция.
- [x] Сборка Android APK и Windows MSI через GitHub Actions.

## Сборка

Требуется JDK 17 и Gradle 8.14.3.

- Android APK: `gradle :androidApp:assembleDebug`
- Windows MSI (на Windows): `gradle :desktopApp:packageMsi`

## Важно

Сейчас это **интерактивный UI-прототип**, а не готовый онлайн-мессенджер. Демо-чат хранит сообщения только в памяти экрана; они не доставляются другим людям. Профиль и коллекция подарков также локальные. Уникальность username пока не гарантируется сервером.

Экран телефона пока не отправляет SMS. Для реальной регистрации необходимо включить Phone Auth в Supabase и настроить SMS-поставщика (например, Twilio или Vonage). До завершения интеграции используйте кнопку «Посмотреть приложение · демо» и не вводите реальные номера.
